-----------------------------
RUFF
-----------------------------
Set ruff version 0.15
uv add --dev "ruff>=0.15.0,<0.16.0"

Check ruff version
uv run ruff --version

uv run ruff check .
It scans your code for errors, potential bugs, stylistic issues, and "code smells" 
(e.g., unused imports, undefined variables, or violation of best practices).

uv run ruff check --fix
ruff automatically fix errors

uv run ruff format
Formating code
To automatically clean up your code's style (indents, line breaks, etc.)
to meet standard PEP 8 requirements:

uv run ruff check --select I --fix
sort imports from short to long

Downgrade the uv version

Turn On Linux/macOS
source .venv/bin/activate
Dont need to use "uv run" command

Turn off VE
deactivate

uv sync 
update the latest dependency from the python.toml into the .venv

uv run 
only run according to the .venv

uv add --dev deptry
uv run deptry .
Check for unused packages in pyproject.toml
1. DEP001 (Missing Dependency)
2. DEP002 (Unused Dependency)
3. DEP003 (Missing Dependency)
