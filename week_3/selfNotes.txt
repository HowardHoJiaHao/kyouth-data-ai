

Step 1: Install the Docker CLI in WSL
Run these commands one by one to update your package list and install the Docker command-line tool:

sudo apt-get update
sudo apt-get install -y docker.io

Step 2: Grant Permissions (Just to be sure)
Since we just installed it, let's make sure your user profile has permission to access it without needing sudo every time:
sudo usermod -aG docker $USER
newgrp docker

Step 3: Test it one more time!
Now that the docker command actually exists in your terminal, run this:
docker ps

Start the server using this command
uv run uvicorn --app-dir src app:app --reload

----------------------
Docker
----------------------

1. Build the image
docker build -t frontend .

2. Build image for all in docker-compose.yml (after that need start service))
docker compose build

docker compose build backend

docker compose build frontend

3. Rebuild everything from scratch (no cache)
docker compose build --no-cache

4. After build image thn need to start it 
docker compose up

5. Run background (-d is detached)
docker compose up -d --build

6. Build image and start but not from scratch (cache)
docker compose up --build

7. Build image and start from scratch (cache) 
docker compose up --build --no-cache

8. Stop services
docker compose down

# Or stop but keep containers (can restart later)
docker compose stop

# 2. Run it
docker run -p 8000:8000 frontend 
docker run -p 8000:8000 --env-file ../.env frontend

---------------------------------
OLLAMA
---------------------------------

1. List all the model in ollama 
ollama list

2. Ollama version 
ollama --version

3. Pull model into Ollama
ollama pull deepseek-r1:1.5b

ollama pull phi3:latest

ollama pull gemma2:2b

4. Run Model
# Run DeepSeek (best for resume analysis)
ollama run deepseek-r1:1.5b

ollama run phi3:latest

ollama run gemma2:2b

5. Remove a model 
ollama rm <model>

6. Run the ollama server so other program can use using port:11434
ollama serve

7. See the port is working
ps aux | grep ollama

8. Kill the ollama server 
sudo kill ollama

9. Query to the endpoint 
curl http://localhost:11434/api/tags
